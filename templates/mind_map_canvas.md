# Mind Map Canvas — Buzan's Laws
## MANB109 Creativity and Innovations

Print **A3, landscape**. One per map. Buzan's method — a map that breaks the laws is a
bubble diagram, and it does not do what a Mind Map does.

> तुमच्या भाषेत लिहा — नकाशा मराठीत काढला तरी चालेल.
> Draw and label in Marathi or Hindi. Only the pitch is in English.

## Before you draw — the laws

**Emphasis**
- [ ] A central **IMAGE**, not a word. Draw it. Badly is fine.
- [ ] At least **three colours** in the central image
- [ ] Branches **thickest at the centre**, thinning as they radiate
- [ ] Vary the size of your printing — bigger nearer the centre

**Association**
- [ ] Connect branches to the centre and to each other
- [ ] Use arrows to link ideas on different branches
- [ ] Use colour as a code — one colour per BOI

**Clarity**
- [ ] **ONE KEY WORD PER LINE.** Not two. Not a phrase.
- [ ] **Print** the words — do not join up your writing
- [ ] The word sits **on** the line, not above or below it
- [ ] **Line length = word length**
- [ ] **Curved** branches. Never straight ruled lines.
- [ ] Paper **landscape**

**Hierarchy**
- [ ] **4–7 Basic Ordering Ideas (BOIs)** as the main branches
- [ ] Everything else hangs beneath a BOI
- [ ] Number the BOIs by importance when the map is done

## After you draw — check yourself

- [ ] Could someone else read this without me explaining it?
- [ ] Is there a branch here I did not expect when I started?
- [ ] Which branch is thinnest? What does that say about what I have not looked at?
