**Fill every row before you judge anything.** The value of SCAMPER is coverage, not brilliance —
seven prompts run badly beats two run well.

| # | Prompt | Ask yourself | Minimum 3 ideas |
|---|---|---|---|
| **S** | **Substitute** | What could I swap out? A material, a person, a place, a step? | |
| **C** | **Combine** | What could I merge this with? Another product, another service, another business? | |
| **A** | **Adapt** | What works elsewhere that I could borrow? Another trade, another town, another era? | |
| **M** | **Modify** | What if it were bigger, smaller, louder, slower, a different colour or shape? | |
| **P** | **Put to another use** | Who else could use this? What else could it do? | |
| **E** | **Eliminate** | What could I remove and still have it work? What if I removed the *most important* part? | |
| **R** | **Rearrange** | What if the order reversed? What if the last step came first? | |

---

## Eliminate deserves extra room

It is the most productive prompt and the least used — people add rather than subtract. Push it.

> What does this business or product do out of **habit** rather than need?
